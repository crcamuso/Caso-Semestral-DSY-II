# Gas El Volcán — Frontend

Tienda online en React (Vite) con panel de administrador. Proyecto académico DSY1104, Evaluación 2.

## Instalación

```bash
npm install
npm run dev
```

## Scripts

| Comando | Qué hace |
|---|---|
| `npm run dev` | Servidor de desarrollo. |
| `npm run build` | Versión de producción. |
| `npm run lint` | Revisa el código. |
| `npm test` | Pruebas Jasmine con Karma (requiere Chrome o Edge). |
| `npm run test:coverage` | Pruebas con cobertura. |
